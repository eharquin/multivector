# VGA 2D Visual Workflow Milestone

**Status:** Planned
**Kind:** Product milestone
**Depends on:** VGA 2D Foundation
**Applies:** To be reviewed after the VGA 2D Foundation
**Date:** 2026-07-29

## Objective

Extend the VGA 2D Foundation with the interactions that prove useful in the
implemented workflow. Candidate capabilities include direct manipulation,
scalar controls and animation, URL sharing, advanced history, display settings,
and deterministic SVG figure export.

## Activation condition

This milestone is intentionally not yet a completion contract. Before
implementation, review the VGA 2D Foundation evidence and decide:

- which semantic entities and degrees of freedom users need to manipulate;
- which source forms support safe inverse editing;
- which viewport and selection behavior proved natural in 2D;
- whether controls, animation, sharing, and figure export belong in one
  milestone or smaller increments;
- which draft APP, EDIT, CMD, CTRL, ANIM, STORE, and INTERACT2D requirements
  should be activated.

Only then shall this document receive detailed `M2D` acceptance criteria and
move from **Planned** to **Draft for review**.

No VGA 1D milestone is implied by this workflow.
